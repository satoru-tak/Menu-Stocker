## 3. データフロー

### 認証フロー

```
User → Frontend → Backend API (/api/v1/users/sign_in)
                      ↓
                  JWT トークン発行
                      ↓
          Cookie/LocalStorage に保存
                      ↓
          以降の API リクエストに JWT 付与
```

### レシピ作成フロー

```
User → レシピフォーム入力 → Frontend
                              ↓
                    バリデーション
                              ↓
              POST /api/v1/recipes
                              ↓
                     Backend API
                              ↓
                  サービス層で処理
                              ↓
                  モデル層でDB保存
                              ↓
              画像アップロード (Active Storage)
                              ↓
                  レスポンス返却
                              ↓
                     Frontend
                              ↓
                    画面更新・通知
```

## 10. 技術的な意思決定

### Next.js App Router を選択した理由
- Server Components による高速なページロード
- 最新の React 機能の活用
- SEO 最適化

### Rails API モードを選択した理由
- RESTful API の実装が容易
- セキュリティ機能の充実
- 豊富なエコシステム

### PostgreSQL を選択した理由
- データの整合性保証
- 複雑なクエリへの対応
- JSON 型のサポート
